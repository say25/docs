# WinGet Tooling

## Upgrade All

```shell
winget update --all
```

### Installing the Tools I Use with WinGet

https://winget.run

##### [Windows Terminal](https://github.com/microsoft/terminal)

```shell
Should be PreInstalled
```

##### [AWS CLI](https://aws.amazon.com/cli/)

```shell
winget install -e --id Amazon.AWSCLI
```

##### AWS VPN Client

```shell
winget install -e --id Amazon.AWSVPNClient
```

##### AWS Session Manager Plugin

```shell
winget install -e --id Amazon.SessionManagerPlugin
```

##### [Slack](https://www.slack.com/)

```shell
winget install SlackTechnologies.Slack
```

##### Visual Studio

```shell
winget install -e --id Microsoft.VisualStudio.2022.Professional 
```

##### [VSCode](https://code.visualstudio.com/)

```shell
winget install vscode 
```

##### [Git](https://git-scm.com/download/win)

```shell
winget install Microsoft.Git
```

##### [GitHub Desktop](https://desktop.github.com/)

```shell
winget install -e --id GitHub.GitHubDesktop.Beta
```

##### [Docker](https://www.docker.com/products/docker-desktop)

```shell
winget install -e --id Docker.DockerDesktop
```

##### [Node LTS](https://nodejs.org/en/)

```shell
winget install nodejs
```

##### SOPS

```shell
winget install -e --id Mozilla.SOPS
```

##### [Terraform](https://www.terraform.io/)

```shell
winget install Hashicorp.Terraform
```

##### [mkcert](https://github.com/FiloSottile/mkcert)

Tool to make certs for SSL locally.

```shell
winget install mkcert
```

##### [PowerShell](https://docs.microsoft.com/en-us/powershell/)

```shell
winget install MicroSoft.PowerShell
```

##### [jq](https://stedolan.github.io/jq/download/)

```shell
winget install jqlang.jq
```
